# Rechi MVP — план улучшения

Дата: 24.10.2026. Ветка: `art/flutter`. Андрей временно не ведёт backend;
полный доступ к проекту у Артёма.

## 1. Цель этапа

Превратить текущий MVP «одно слово + несколько фраз» в тренировку с
категориями и подробной обратной связью:

1. Три категории: **слова**, **словосочетания**, **короткие предложения
   4–6 слов**.
2. Больше упражнений в каждой категории.
3. Для словосочетаний и предложений — **фонемный разбор каждого слова**:
   слово, его балл и звуки с баллами.
4. Запись до 20 секунд, чтобы влезали предложения 4–6 слов.
5. Сохранить обратную совместимость API: текущие поля `score`,
   `phoneme_scores`, `problematic` остаются; добавляются `category` и
   `words`.

## 2. Текущее состояние (факт)

- Реальный SpeechSuper подключён: `word.eval.ru` и `sent.eval.ru` проверены.
- `sent.eval.ru` возвращает `words[]` с `scores` и `phonemes[]` — можно
  показывать разбор по словам.
- Парсер нормализует латинские гласные SpeechSuper (`a → А` и т.п.).
- В seed 17 упражнений: 14 слов, 3 фразы.
- Клиент различает слово/фразу по пробелу, но не знает категорий.
- Агрегированные фонемы фразы смешиваются в один список; отдельных
  результатов по словам нет.
- Максимум записи — 10 секунд; для предложений 4–6 слов этого мало.

## 3. Целевая модель

### 3.1. Категория упражнения

`Exercise.category` — одно из:

| API value | UI | Смысл |
|---|---|---|
| `word` | Слова | одно слово |
| `phrase` | Словосочетания | 2–3 слова |
| `sentence` | Предложения | 4–6 слов |

`GET /api/v1/exercises/next?category=word|phrase|sentence` — необязательный
фильтр. Без параметра — случайное упражнение из всех категорий (обратная
совместимость).

### 3.2. Разбор по словам

Ответ `/api/v1/assess` дополняется:

```json
{
  "score": 78,
  "phoneme_scores": { "М": 80, "А": 90 },
  "problematic": ["Р"],
  "words": [
    {
      "text": "мама",
      "score": 91,
      "phoneme_scores": { "М": 90, "А": 92 }
    },
    {
      "text": "мыла",
      "score": 84,
      "phoneme_scores": { "М": 88, "Ы": 80, "Л": 85, "А": 83 }
    }
  ]
}
```

- `words` идёт в порядке произношения.
- `score` слова — `word.scores.overall` (fallback `pronunciation`).
- `phoneme_scores` внутри слова — уникальные звуки слова (минимум при
  повторе).
- Верхнеуровневые `phoneme_scores` — агрегат по всем словам (минимум).
- Старые клиенты, не читающие `words`, продолжают работать.
- В БД пока сохраняем агрегат, как раньше; per-word нужен для экрана
  результата. Историю по словам можно добавить следующим этапом.

### 3.3. Запись

- Максимум: **20 секунд**.
- WAV PCM16, 16 кГц, моно, максимум `20 * 16000 * 2 + 44 = 640 044` байта.
- Минимум 0,6 секунды.
- Таймаут `/assess` на клиенте: 60 секунд.

## 4. UX

### Home

- Блок «Что тренируем?»: три крупных чипа/карточки.
- Выбранная категория передаётся в `ExerciseScreen`.
- Кнопка «Начать тренировку» запускает выбранную категорию.
- Под кнопкой — подсказка категории: «1 слово», «2–3 слова»,
  «4–6 слов».

### Exercise

- Для слова: крупный текст + чипы звуков (как сейчас).
- Для фразы/предложения: крупный текст с переносом; агрегированные чипы
  звуков не показываем, чтобы не было визуального шума. Вместо них —
  подпись «Проверим звуки в каждом слове».
- Таймер и прогресс записи — до 20 секунд.
- Подсказка «произнесите слово/фразу» зависит от категории.

### Result

- Общая оценка и фидбек — как сейчас.
- Для слова: карточка «Звуки» (как сейчас).
- Для фразы/предложения: карточка **«По словам»**:
  - каждое слово отдельной строкой;
  - балл слова;
  - чипы всех звуков слова с баллами и красной рамкой для слабых;
  - если сервер не вернул `words`, fallback на агрегированную карточку.
- Советы по слабым звукам — как сейчас (агрегат).

## 10. Риски

| Риск | Митигация |
|---|---|
| `sent.eval.ru` вернёт слова без фонем на другой речи | fallback: показываем балл слова без чипов; агрегат остаётся |
| Слишком длинная запись на слабом устройстве | лимит 20 с, понятное авто-сообщение |
| Категория пустая после сида | 404 и понятный текст; seed гарантирует контент |
| Разные написания слов SpeechSuper | сопоставляем по порядку `words[]`; текст берём из ответа |
| Старые клиенты без `words` | поле опционально, старый UI работает |
