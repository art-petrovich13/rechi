# Rechi — решения и план развития

Обновлено: 06.11.2026. Подробный разбор проблем: [`PROJECT_ANALYSIS.md`](PROJECT_ANALYSIS.md).

## 1. Решения

| Вопрос | Решение |
|---|---|
| Аудитория | взрослые и дети, с явным разделением в приложении |
| Повторение | слова с низким баллом возвращаются, плюс подбираются похожие по группе звуков |
| База упражнений | сильно расширяем, пока без логопеда; позже специалист её проверит |
| Стадия | MVP, дальше полноценное приложение для iOS и Android |
| Платформа | Flutter остаётся, потому что общий код нужен для мобильного приложения |
| Команда | главный разработчик Артём, Андрей пока не участвует |

## 2. Целевая архитектура

### 2.1. Подбор упражнений

Сейчас любая попытка закрывает упражнение навсегда. Нужен подбор, который ничего
не исчерпывает. Порядок приоритетов при выдаче:

1. **Повтор.** Упражнение с низким последним баллом, если прошло время.
2. **Похожее.** Упражнение на те же слабые звуки или их группу.
3. **Новое.** Ещё не пройденное, подходящее по уровню.
4. **Закрепление.** Давно не встречавшееся из хорошо пройденных.

404 остаётся только для случая, когда контента нет совсем. «На сегодня всё»
становится дневной нормой, а не концом базы.

### 2.2. Группы звуков

Группы хранятся в одном справочнике на сервере:

| Группа | Звуки |
|---|---|
| Шипящие | Ш, Ж, Ч, Щ |
| Свистящие | С, З, Ц |
| Сонорные | Р, Л, М, Н |
| Заднеязычные | К, Г, Х |
| Парные глухие и звонкие | П/Б, Т/Д, К/Г, С/З, Ш/Ж, Ф/В |
| Гласные | А, О, У, Ы, И, Э |

Группы подбираются по слабому звуку: при слабом Ш пользователь получает слова с Ш,
затем с Ж, Щ, Ч. Парные группы нужны для тренировки различения: «шар — жар».

Условие: сначала нужен единый словарь фонем. Сейчас упражнения смешивают буквы и
звуки (Я, Ю, Ё, Ь рядом с фонемами), поэтому подбор будет работать неточно.
Словарь строится по фактическим ответам SpeechSuper.

### 2.3. Две аудитории

- Поле `audience` у пользователя: `adult` или `child`, выбор при первом входе.
- Метка у упражнения: для взрослых, для детей или обе группы.
- Для детей: картинки, простые слова, обращение на «ты», поддержка без сравнения
  с баллом. Для взрослых: обращение на «вы», более взрослая лексика.
- Тексты интерфейса выносятся в словарь по аудитории.

### 2.4. Контент

- Упражнения переезжают из `seed.py` в файлы данных со стабильным ключом.
- Поля: текст, транскрипция, группы звуков, аудитория, уровень, статус
  `draft` или `reviewed`.
- Статус нужен для будущей проверки логопедом.
- Автоматическая проверка: транскрипция, уникальность, покрытие звуков.
- Цель первого шага: 500+ упражнений, минимум 15 слов на каждый согласный.

### 2.5. Подготовка к мобильному приложению

Что сейчас привязано к web или Telegram и должно быть вынесено за абстракции:

| Сейчас | Нужно |
|---|---|
| вход только через `initData` | интерфейс авторизации с реализациями Telegram и мобильной |
| `users.telegram_id` обязателен | отдельная таблица `user_identities` для способов входа |
| запись возвращает `blob:` URL | интерфейс записи: на мобильных файл, на web blob |
| `telegram_web_app` импортируется напрямую | мост через условный импорт |
| JWT живёт в памяти | защищённое хранилище и обновление токена |
| клиент обновляется мгновенно | проверка минимальной версии, API без ломающих изменений |
| только онлайн | очередь отправки записи при плохой сети |

Для магазинов понадобятся политика конфиденциальности, удаление аккаунта, согласие
родителей для детей и проверка правил для детских приложений и здоровья.
